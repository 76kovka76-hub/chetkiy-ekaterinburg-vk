# 🔥 Чёткий Екатеринбург — бесплатный VK-бот

Полностью отдельный проект для [сообщества «Чёткий Екатеринбург»](https://vk.ru/club243223597). **Не связан с автомобильным сообществом или «Чётким Ярославлем»**: у него свой ID, история, токен и расписание.

## Как работает
- До **30 постов за сутки** по часовому поясу **Екатеринбурга (Asia/Yekaterinburg, UTC+5)** — один в каждом 48-минутном слоте. GitHub Actions проверяет расписание примерно каждые 5 минут; возможны задержки.
- Бесплатно ищет свежие городские новости через две поисковые RSS-ленты Google Новости по **Екатеринбургу**, проверяет возраст, название города и повторение ссылок/похожих заголовков.
- Публикация: короткое предложение по исходному заголовку с обращением «Братва», «Пацаны», «Народ» и **три ранее не использованных тематических хэштега** с основой «Екатеринбург».
- Если подходящих новостей нет, заполняет **некоторые дневные слоты** вопросами и мини-играми: знакомства, фото обеда, районы Екб, Плотинка, Уралмаш, прогулки и т. п.
- Интерактивные посты: **до 4 в день**, минимум **3 часа** между ними, только **08:00–22:59** по времени Екатеринбурга; один и тот же вопрос — не чаще раза в 7 дней.
- Все посты вместе имеют лимит **до 30/сутки**. История сообщений, ссылок и хэштегов хранится в `history.json`, чтобы не публиковать одно и то же.
- **Без OpenAI API**, подписок, внешней базы данных и платного ИИ. Python и публичный GitHub Actions со стандартным раннером используются без отдельной оплаты в рамках условий GitHub.

## Подключение токена — только один секрет
1. Откройте сообщество [ВК](https://vk.ru/club243223597) → **Управление → Работа с API → Ключи доступа**. Создайте **ключ сообщества** с правом публиковать на стене.
2. Откройте [GitHub Secrets](https://github.com/76kovka76-hub/chetkiy-ekaterinburg-vk/settings/secrets/actions) → **New repository secret**.
3. **Name:** `EKATERINBURG_VK_TOKEN`. **Secret:** ваш токен сообщества, а не личный токен и не токен Ярославля.
4. Нажмите **Add secret**. Не присылайте секрет в чат и не добавляйте в исходный код.

**ID группы уже указан в коде:** `243223597`. Отдельный `VK_GROUP_ID` создавать не нужно, а `YAROSLAVL_VK_TOKEN` здесь не используется.

## Статус: автоматическая публикация включена
- В [основном workflow](https://github.com/76kovka76-hub/chetkiy-ekaterinburg-vk/blob/main/.github/workflows/publish.yml) установлено `DRY_RUN: "false"`. По расписанию бот может **публиковать реальные записи в ВК**.
- [Безопасная проверка токена и RSS](https://github.com/76kovka76-hub/chetkiy-ekaterinburg-vk/actions/runs/43251443708): секрет `EKATERINBURG_VK_TOKEN` обнаружен, **18/18 тестов прошли**, RSS выдаёт новости Екатеринбурга.
- Реальный доступ токена к `wall.post` подтвердится при первой успешной публикации: в журнале должна появиться строка `Опубликовано: <post_id>` или `Опубликована игра: <post_id>`.
- Время Екатеринбурга — UTC+5; до 30 постов в сутки, из них не более 4 интерактивных. Запуск GitHub Actions примерно каждые 5 минут, возможны пропуски и задержки.
- [Смотреть публикации в группе ВК](https://vk.ru/club243223597), [смотреть историю публикаций](https://github.com/76kovka76-hub/chetkiy-ekaterinburg-vk/blob/main/history.json), [запуски](https://github.com/76kovka76-hub/chetkiy-ekaterinburg-vk/actions/workflows/publish.yml).
- Чтобы остановить публикации, замените `DRY_RUN: "false"` на `DRY_RUN: "true"` или отключите workflow в GitHub Actions.

## Ограничения
- RSS-подборки Google News могут менять доступность. **На этом новом проекте их доступность и фактическая публикация ещё не проверены.**
- Бесплатный шаблонизатор сохраняет фактический смысл заголовков, но не заменяет редактора: нет полноценной автоматической проверки истинности и гарантии от смысловых дублей из разных СМИ.
- Бот не придумывает фактов и не копирует чужие фотографии. Если не нашлось подходящих новостей или свободных интерактивных тем, слот может остаться пустым.
- Cron GitHub Actions не гарантирует выполнение точно в назначенную минуту.
- Предельные 30 постов — **не гарантия ежедневного количества**, а защитный лимит.

## Структура
- `main.py` — новости, проверка повторов, бесплатный формат постов, VK API.
- `engagement.py` — больше 50 вопросов и игр с ограничением частоты.
- `test_bot.py` — 18 автономных тестов.
- `history.json` — история только Екатеринбурга, стартует пустой.
- `.github/workflows/publish.yml` — расписание и ручной тест.
